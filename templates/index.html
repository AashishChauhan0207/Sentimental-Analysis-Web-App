About This Project

This sentiment analysis tool uses machine learning to classify text as positive, neutral, or negative. The model was trained on a dataset of product reviews from the electronics category.

The application utilizes:

  • Natural Language Processing (NLP) techniques for text preprocessing
  • TF-IDF (Term Frequency-Inverse Document Frequency) for feature extraction
  • Logistic Regression for classification
  • Flask for the web application backend
  • JavaScript and Bootstrap for the frontend
